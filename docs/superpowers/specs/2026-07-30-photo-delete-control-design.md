# 照片删除控件设计

## 目标

缩小当天照片卡片的删除入口，移除缩略图下方的图片名称和文字删除按钮，同时保持误删确认。

## 界面与交互

- 每张照片保留为固定比例的可点击缩略图；点击缩略图本身打开大图查看。
- 删除入口为覆盖在缩略图右上角的圆形 `×` 图标按钮，视觉上与添加照片、保存记录等主要操作区分。
- 按钮在触摸设备上保留足够的可点击区域，并提供中文无障碍名称，例如“删除当天照片”。
- 点击 `×` 后调用浏览器确认框，文案维持“确定删除这张照片吗？”。确认后才删除；取消不改变照片。
- 不再渲染图片名称或底部“删除”文字按钮。

## 范围与边界

- 只修改当前本地照片卡片的展示和删除入口，不改变照片本地存储、数量上限、上传、大图查看或未来云端相册方案。
- 不改动当天记录、日历状态或 Supabase 数据库。

## 测试

- 新增组件测试，验证图片名称与文字删除按钮不出现。
- 验证右上角删除按钮可访问、取消确认不会删除、确认后调用仓库删除并刷新列表。
- 保留缩略图打开大图的现有行为。
