# 密码重置六位验证码设计

## 目标

将现有的“邮箱重置链接”流程改为“邮箱六位验证码”流程，避免用户点击邮件链接时受到设备、VPN或浏览器跳转问题影响。

## 用户流程

1. 用户在登录页点击“忘记密码？”。
2. 输入邮箱并发送验证码。
3. Supabase 重置密码邮件显示六位验证码。
4. 用户在网页输入验证码并验证。
5. 验证成功后进入设置新密码页面。
6. 输入两次新密码并保存，成功后返回登录页。

## 技术方案

- 继续使用 Supabase Auth，不新增自建验证码服务或数据库表。
- Supabase 邮件模板使用 `{{ .Token }}` 显示验证码。
- 前端使用 `verifyOtp({ email, token, type: 'recovery' })` 验证验证码。
- 验证成功后调用现有 `updateUser` 密码更新接口。
- Supabase 负责验证码过期、一次性使用和失败校验。

## 页面与错误处理

- 忘记密码页面：邮箱输入、发送验证码、返回登录。
- 验证码页面：六位验证码输入、验证、重新发送、返回登录。
- 设置新密码页面：新密码和确认密码输入。
- 显示邮箱格式错误、验证码错误或过期、发送失败、密码不一致等提示。
- 密码至少 6 位；保存成功后退出恢复会话。

## 验证范围

- 为 AuthGateway 增加验证码验证接口及测试替身。
- 覆盖发送验证码、验证成功、验证失败、密码更新和页面跳转测试。
- 运行完整测试和生产构建。
- 部署后在正式网址验证完整流程。
