# 设置与账号资料设计说明

## 目标

简化共享日历顶部栏，将身份、退出账号和取消配对等操作统一放入设置，同时增加可展开的账号资料区域。

## 顶部栏

- 删除“留一页给我们”左侧爱心图标。
- 保留纯文字品牌名“留一页给我们”。
- 顶部右侧只保留消息通知按钮和设置入口按钮。
- 当前身份、取消配对、退出账号不再直接显示在顶部栏。

## 设置面板

设置面板自上而下固定为：

1. 账号资料
2. 当前身份
3. 取消配对
4. 退出账号

“账号资料”默认折叠，只显示一行入口。点击后展开以下三项：

- 用户名：显示当前用户名，点击后进入编辑状态；
- 邮箱：显示当前绑定邮箱，点击后进入邮箱修改流程；
- 修改密码：进入修改密码表单。

再次点击账号资料标题可以收起内容。

## 账号资料行为

- 用户名修改通过 `profiles.display_name` 保存，并立即更新页面显示；
- 邮箱修改使用 Supabase Auth 的邮箱更新接口，要求新邮箱完成验证后生效；
- 修改密码使用 Supabase Auth 的密码更新接口；
- 所有保存操作有加载状态、成功提示和可读错误提示；
- 不在前端显示或保存密码。

## 配对操作

- 当前身份以只读信息展示；
- 取消配对保持现有二次确认、历史内容保留和原配恢复逻辑；
- 退出账号保持现有会话退出行为；
- 危险操作使用明显但克制的警示色，避免与普通设置混淆。

## 响应式与可访问性

- 设置面板在桌面端以右侧抽屉或浮层呈现，在手机端使用接近全宽的面板；
- 设置入口按钮使用齿轮图标并提供无障碍名称“设置”；
- 折叠项使用按钮和 `aria-expanded` 表示展开状态；
- 弹窗可通过关闭按钮和 Escape 关闭，输入框支持键盘操作。

## 验收标准

1. 顶部栏不再显示爱心、当前身份、退出账号和取消配对。
2. 顶部栏只显示消息通知和设置入口。
3. 设置项目顺序正确。
4. 账号资料默认折叠，点击后才显示用户名、邮箱和修改密码。
5. 用户名、邮箱和密码修改分别能显示正确的加载、成功和错误状态。
6. 取消配对和退出账号功能行为不回归。
